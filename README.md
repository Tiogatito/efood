# efood

Projeto de restaurantes desenvolvido com React, TypeScript, Styled Components e React Router, seguindo o layout fornecido pela EBAC.

## Executar

Requisito: Node.js 24.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## Etapas

1. Layout, componentes e navegação.
2. Conteúdo da API e modal de produtos.
3. Carrinho com Redux e total da compra.
4. Entrega, pagamento e confirmação pela API.

Layout: https://www.figma.com/file/JjduV2Tg713TzYUUsees8b/efood
